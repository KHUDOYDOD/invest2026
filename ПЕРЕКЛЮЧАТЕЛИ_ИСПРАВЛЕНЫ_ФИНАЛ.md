- **Проблема**: В `app/api/deposit/route.ts` была синтаксическая ошибка - дублирование `const client = await pool.connect()`
- **Решение**: Исправлена структура кода, разделены клиенты для проверки статуса и основной логики

### 2. SQL запросы с поддержкой NULL
- **Проблема**: В базе данных `is_launched` может быть `null`, но запросы искали только `false`
- **Решение**: Все API используют правильный запрос: `WHERE (is_launched = false OR is_launched IS NULL)`

- **Проблема**: Switch компоненты работали некорректно
