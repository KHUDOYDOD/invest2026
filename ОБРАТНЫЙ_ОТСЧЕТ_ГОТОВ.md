## Как протестировать:

### Вариант 1: Быстрый тест (2 минуты)
```bash

cd /home/root11/invest2026
node set-countdown-test.js
```

Это установит время запуска через 2 минуты. Откройте сайт и увидите обратный отсчет.

### Вариант 2: Установить свое время
Отредактируйте `set-countdown-test.js` и измените:
```javascript
const countdownEnd = new Date(now.getTime() + 2 * 60 * 1000); // +2 минуты
```

На нужное вам время, например:
```javascript
const countdownEnd = new Date(now.getTime() + 24 * 60 * 60 * 1000); // +24 часа
```
