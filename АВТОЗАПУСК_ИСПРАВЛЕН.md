## 🐛 Если ничего не показывается:

### Проверьте в консоли:
1. Есть ли ошибки (красный текст)?
2. Что показывает `🚀 Project Launches Debug`?
3. Есть ли `launch_date` в данных проекта?

### Возможные проблемы:

#### Проблема 1: `launch_date` = null
Если в логах вы видите:
```
❌ Launch date is missing for launched project: {...}
```

Решение: Запустите проект вручную с правильной датой:
```bash
node launch-project-now.js
```

#### Проблема 2: Проект не обновляется в базе
Если в логах вы видите:
```
❌ Error launching project: ...
```

Решение: Проверьте API endpoint вручную:
```bash
curl -X PATCH http://213.171.31.215/api/admin/project-launches/af7b9a96-dfec-4ab8-8f9d-810fa8c131b0 \
  -H "Content-Type: application/json" \
  -d '{"is_launched": true, "launch_date": "2026-04-05T06:19:02.763Z"}'
```

#### Проблема 3: Компонент не рендерится
Если в логах вы НЕ видите `🚀 Project Launches Debug`, значит компонент не загружается.

Решение: Проверьте, что компонент подключен в `hero-section.tsx`:
```typescript
import { ProjectLaunches } from "@/components/project-launches"

// В JSX:
<ProjectLaunches />
```

```typescript
if (body.launch_date !== undefined) updates.launch_date = body.launch_date
if (body.is_launched !== undefined) updates.is_launched = body.is_launched

const setClause = Object.keys(updates).map((key, index) => `${key} = $${index + 1}`).join(', ')
```

### Изменения в компоненте:
```typescript
// Добавлено логирование
console.log('🚀 Project Launches Debug:', {
  totalLaunches: launches.length,
  activeLaunches: activeLaunches.length,
  launchedProjects: launchedProjects.length,
  launches: launches

// Добавлена проверка launch_date
if (!launchedProject.launch_date) {
  console.error('❌ Launch date is missing for launched project:', launchedProject)
  return null
}

// Улучшен автозапуск
fetch('/api/admin/project-launches/' + launch.id, {
  method: 'PATCH',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ 
    is_launched: true,
    launch_date: new Date().toISOString()
  })
}).then(response => {
  console.log('✅ Project launch response:', response.status)
  return response.json()
}).then(data => {
  console.log('✅ Project launched successfully:', data)
  setTimeout(() => {
    window.location.reload()
  }, 500)
}).catch(error => {
  console.error('❌ Error launching project:', error)
})
```
