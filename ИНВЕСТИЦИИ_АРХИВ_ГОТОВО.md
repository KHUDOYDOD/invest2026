  - Средний ROI

  - Сумму инвестиции
  - Заработанную прибыль
  - ROI (доходность)
  - Итого получено (с прибылью)
  - Даты начала и окончания
  - Значок "✅ Завершена"

### 3. Улучшенный дизайн
- Красивые градиентные карточки
- Анимации при наведении
- Иконки и эмодзи для лучшей визуализации
- Пульсирующие эффекты
- Современные цвета и тени

## 📊 Как это работает:

### Активные инвестиции:
```typescript
const activeInvestments = investments.filter(inv => inv.status.toLowerCase() === 'active')
```

### Завершенные инвестиции (Архив):
```typescript
const completedInvestments = (data.investments || []).filter(
  (inv: any) => inv.status.toLowerCase() === 'completed'
)
```
