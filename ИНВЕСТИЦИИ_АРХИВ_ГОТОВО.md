# ✅ Автоматическое перемещение завершенных инвестиций в архив

## Что сделано

Добавлена автоматическая система обновления статуса инвестиций, которая переносит завершенные инвестиции из вкладки "Активные" в "Архив".

## Как это работает

### 1. Автоматическое обновление статуса

В API `/api/dashboard/all/route.ts` добавлена логика, которая при каждой загрузке данных дашборда:

1. Проверяет все активные инвестиции пользователя
2. Сравнивает дату окончания с текущей датой
3. Автоматически обновляет статус с `active` на `completed` для истекших инвестиций

```typescript
// АВТОМАТИЧЕСКОЕ ОБНОВЛЕНИЕ СТАТУСА ИНВЕСТИЦИЙ
await query(
  `UPDATE investments 
   SET status = 'completed' 
   WHERE user_id = $1 
   AND status = 'active' 
   AND (created_at + INTERVAL '1 day' * (
     SELECT duration_days 
     FROM investment_plans 
     WHERE id = investments.plan_id
   )) <= NOW()`,
  [userId]
)
```

### 2. Фильтрация в компонентах

**Активные инвестиции** (`components/dashboard/investments-list.tsx`):
- Показывает только инвестиции со статусом `active`
- Отображает обратный отсчет до завершения
- Показывает прогресс и текущую прибыль

**Архив** (`components/dashboard/investments-history.tsx`):
- Показывает только инвестиции со статусом `completed`
- Отображает итоговую статистику:
  - Всего завершено инвестиций
  - Общая прибыль
  - Средний ROI
- Красивые карточки с детальной информацией о каждой завершенной инвестиции

## Когда инвестиция переходит в архив

Инвестиция автоматически перемещается в архив когда:
- ✅ Прошло количество дней, равное сроку инвестиции (duration_days)
- ✅ Прогресс достиг 100%
- ✅ Осталось 0 дней до завершения

## Что видит пользователь

### Вкладка "Активные"
- Только работающие инвестиции
- Обратный отсчет в реальном времени
- Текущая прибыль и прогресс

### Вкладка "Архив"
- Завершенные инвестиции
- Итоговая статистика по всем завершенным инвестициям
- Детальная информация о каждой инвестиции:
  - Сумма инвестиции
  - Заработанная прибыль
  - ROI (Return on Investment)
  - Даты начала и окончания

## Преимущества

1. **Автоматизация**: Не требуется ручное управление статусами
2. **Чистота интерфейса**: Активные и завершенные инвестиции разделены
3. **Прозрачность**: Пользователь видит полную историю своих инвестиций
4. **Статистика**: Красивая визуализация результатов в архиве

## Технические детали

- Обновление статуса происходит при каждом запросе к `/api/dashboard/all`
- Используется SQL запрос с подзапросом для получения duration_days из investment_plans
- Проверка выполняется только для инвестиций текущего пользователя
- Обновляются только инвестиции со статусом `active`
