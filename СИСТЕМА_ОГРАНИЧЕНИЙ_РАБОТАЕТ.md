## 🛠️ Исправленные проблемы

### Проблема с SSL сертификатом
- **Проблема:** Nginx не мог прочитать SSL сертификаты
- **Решение:** Исправил права доступа к файлам сертификатов
- **Команды:**
```bash
sudo chmod 755 /etc/letsencrypt/live
sudo chmod 755 /etc/letsencrypt/archive  
sudo chmod 644 /etc/letsencrypt/live/tradepo.ru/*
sudo chmod 644 /etc/letsencrypt/archive/tradepo.ru/*
sudo systemctl restart nginx
```

### Проблема с тестированием
- **Проблема:** Тесты через HTTP не работали
- **Причина:** Сайт работает только через HTTPS с SSL
- **Решение:** Переключился на тестирование через HTTPS

## 🎛️ Как управлять системой

### Админ панель
Откройте: https://tradepo.ru/admin/project-launches

### Переключатели функций
В админ панели есть 4 чекбокса с белым фоном и черными границами:
- ☑️ **Отключить регистрацию** 
- ☑️ **Отключить инвестиции**
- ☑️ **Отключить пополнение** 
- ☑️ **Отключить вывод средств**

### Логика работы
1. **До запуска проекта:** Все отмеченные функции отключены (возвращают 403 Forbidden)
2. **После запуска проекта:** Все функции автоматически включаются
3. **Без активных проектов:** Все функции включены по умолчанию
