## 🎨 Интерфейс управления

### Форма проекта запуска:
```
🔒 Управление функциями сайта до запуска
┌─────────────────────────────────────────┐
│ 🚫 Отключить регистрацию        [ON/OFF] │
│ 📈 Отключить инвестиции         [ON/OFF] │
```

### Индикаторы в списке:
- 🚫 Регистрация отключена
- 📈 Инвестиции отключены  
- 💰 Пополнение отключено
- 💸 Вывод отключен

## 🔄 Логика работы

### До запуска проекта:
1. **Админ настраивает** какие функции отключить
2. **Система блокирует** выбранные функции
3. **Пользователи видят** сообщения об отключении

### После запуска проекта:
1. **Все функции автоматически включаются**
2. **Ограничения снимаются**
3. **Сайт работает в полном режиме**
