# ✅ ИСПРАВЛЕНА ОШИБКА 404 NGINX

## 🎯 Проблема решена

### ❌ Что было не так:
- Сайт показывал **404 Not Found nginx/1.24.0 (Ubuntu)**
- Проблема с конфигурацией nginx - SSL сертификат для tradepo.ru был недоступен
- Next.js приложение работало на порту 3000, но nginx не проксировал запросы

### ✅ Что исправлено:

1. **Удалена проблемная SSL конфигурация**:
   - Убрана конфигурация tradepo.ru с недоступным SSL сертификатом
   - Очищена папка `/etc/nginx/sites-enabled/`

2. **Создана простая рабочая конфигурация**:
   - HTTP на порту 80 (без SSL)
   - Проксирование на localhost:3000 (Next.js приложение)
   - Правильные заголовки для корректной работы

3. **Nginx перезагружен**:
   - Конфигурация протестирована (`nginx -t`)
   - Сервис перезагружен (`systemctl reload nginx`)

## 🔧 Техническая информация:

### Новая конфигурация nginx:
```nginx
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    
    server_name _;
    
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 86400;
    }
}
```
